<h3 align="center">Coffee, code, repeat.</h3>

I spend most of my time wiring together containers, writing Terraform configs, and wondering why that one pipeline broke at 2am. There's something satisfying about getting a deployment to flow cleanly from a git push all the way to production — Linux, Docker, Kubernetes, the whole chain. Lately I've been thinking a lot about how the best infrastructure is the kind nobody notices.

#### About me

- 🔭 Tinkering with a GitHub Actions workflow that self-heals flaky deploys.
- 🌍 Based in Singapore
- ⚡ Fun fact: I debug faster with music on
- 👯 Open to collaborating on open-source projects
